# Support

For installation problems, UI bugs, firmware compatibility reports or feature requests, use the repository issue templates.

Before opening an issue:

1. run `./scripts/test.sh` on your checkout;
2. run `./scripts/status.sh <LINKPI_IP>` when the device is reachable;
3. note the LinkPi model, SoC and firmware versions;
4. remove passwords, stream keys, private URLs and personal paths from logs/screenshots.

Security vulnerabilities must follow `SECURITY.md` and should not be filed as public issues.

This is an unofficial community project and is not LinkPi customer support. Hardware warranty, firmware account access and vendor-specific service requests should go through the vendor's official support channels.
